# Yoha_Eventos

Plataforma web para encontrar fornecedores e organizar eventos em Angola.

## Estrutura

- `frontend/` — site (HTML, CSS e JavaScript, sem dependências)
- `index.html` — redirecciona para `frontend/index.html`

## Ver localmente

Abra a pasta no VS Code e use a extensão **Live Server** (botão *Go Live*).

## Páginas

Início, Fornecedores, Perfil do fornecedor, Planeador (orçamento, convidados, mesas, checklist,
fornecedores contratados), Calculadora de orçamento, Entrar / Criar conta, Para fornecedores,
Sobre nós e Contacto.

> Nota: as contas e os dados ficam, por agora, guardados no navegador (localStorage).
> Para produção é necessário um backend.
